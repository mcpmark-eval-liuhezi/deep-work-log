# Deep Work Log

## Goal

Log one deep-work session per day and keep a weekly heartbeat going so progress stays visible.

## Method

- Block a distraction-free period each morning and focus on a single task.
- Log the session in `notes/session-01.md` (Date, Focus, Duration, Notes).
- Run the `heartbeat` workflow at the end of each week to confirm the log is alive.
